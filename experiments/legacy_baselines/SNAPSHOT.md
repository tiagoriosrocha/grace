# legacy_baselines

Source project: `proposta-tese-alternativa-5`. All files in the representative run's
`source_sha256` map are preserved byte for byte. See `provenance/source_files.json`.
The historical baseline snapshot restores `hover_exp/x23_data.py` from commit
`54b668d` to match the recorded training code. Other snapshots use their existing files.

`data/` is a relative link to the shared exports. The original runner writes new
runs inside this snapshot's `results/`; published runs live under the root `results/`.
`README.original.md` describes the broader development project and includes systems
outside the current paper. Use the root README for the publication protocol.
